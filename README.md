# AI智能心灵伙伴

AI智能体创新设计 - 您的专属情感倾听者、思想交流者、创意启发库与自然疗愈师。

通过多维数字生命形态、智能情绪气象站、心灵树洞与呼吸疗愈区，开启温暖的心灵奇遇。

## 本地运行

**前置条件：** Node.js

1. 安装依赖：
   ```bash
   npm install
   ```
2. 在 `.env.local` 中配置你的硅基流动 API Key：
   ```
   QWEN_API_KEY=你的硅基流动Key
   ```
3. 运行应用：
   ```bash
   npm run dev
   ```

## 技术栈

- **前端**：React + Vite + Tailwind CSS
- **后端**：Express
- **AI 模型**：Qwen/Qwen3.6-27B（通过硅基流动 API）
